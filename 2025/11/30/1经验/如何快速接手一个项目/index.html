如何快速接手一个项目

Created2025-11-30|Updated2026-08-24|经验总结
|Post Views:

（注：一开始最好不要直接看项目具体的逻辑，先跑起来再说，这个思想很重要！！！）
**1、**​ ******（也是最重要的一步）******​ ，按照上一个开发者的 readme 配好环境，（如果没有 readme，那就量力而行，看看这个框架自己熟不熟悉需要哪些环境，或者 CSDN 一下，一般项目都有 readme 的）
2、项目跑起来了（注：这里跑起来的意思是没有报错❎，有警告⚠️不鸟他）
3、代码跑起来了之后，到处玩玩这个项目，看看点击那个按钮有什么效果
4、等自己玩的差不多知道它是用来干嘛的时候，再尝试改项目
