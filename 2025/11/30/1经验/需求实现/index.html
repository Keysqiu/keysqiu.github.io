需求实现

Created2025-11-30|Updated2026-08-25|经验总结
|Post Views:

实现一个需求时，无论是别人给的还是自己想的，切记第一点：一开始一定不要想的很复杂，先想最简单的，并且实现它，拿QQ来说，刚开始出来的时候也没多美观啊，只实现了最基本的两个客户端之前互相聊天（​开始可能也没考虑什么高并发啊，这些乱七八糟的****​ ），后面界面的变化都是后来的事情了，反正你就记得，先有，你才有改的余地，不管你怎么实现的，只要你能实现预期的效果就行，“不管白猫黑猫，只要能抓到老鼠的就是好猫”

基本数据结构
哈希表 哈希表的思想就是一个数组的下标嵌套另一个数组的值，形成一个键值的对应关系，将键作为数组的索引，数组中索引为i存储的值就是它对应的值 栈 栈的指针为什么一开始赋值为-1，这是因为当压入数据时，可以使（下标++）的代码不用特殊处理，也就是一直（下标++） 二叉树的遍历 由前序知道树的根节点是哪个，再到中序中找他的左右子树，如果没有就是空，如果有多个就继续在前序中把下一个当根节点（理解为遍历，一定要一个个遍历，不要怀疑，肯定对的） 其实用到了递归的思想，一点点地拆分，您细品就知道了！ （遍历看的时候，先总体看，再细分）

注释规范
文件注释： @file - 文件名 @author - 作者 @version - 版本 @date - 日期 @note - 注解 函数注释： @brief - 简短说明 @param - 输入参数 @arg - 输入参数取值 @return - 返回值 @retval - 返回值取值 @sa -参考资料(see also) @code -在文档当中嵌入代码块，代码结尾处使用@endcode标签 @addtogroup、@{、@}添加到一个分组，如果分组不存在，自动创建 @todo -将要做的事 @since - 从哪个版本起有了这个函数 多行注释：/** * */ 单行注释：// 根据Doxygen生成帮助文档。 命名空间：禁止使用 using 指示 引入整个命名空间的标识符号(污染命名空间)，在命名空间的最后注释出命名空间的名字。
