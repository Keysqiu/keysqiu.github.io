Git安装

Created2025-11-30|Updated2026-08-24|Git
|Post Views:

生成的.git文件夹中就那个config文件比较重要一点，里面配置了远程仓库信息，其他的没啥用，几乎都是二进制文件

一、绑定远程仓库

1.1 安装Git（Windows版安装）

**链接：**​https://pan.baidu.com/s/1n5gAh5QqVwg8f3H5b3ydNA?pwd=so14
提取码：so14
–来自百度网盘超级会员V5的分享
改一下安装路径，然后不断下一步即可

1.2 随便在一个文件夹里面，鼠标右键，选择"Git Bash Here"，打开Git命令窗口

git config --global user.name "SIE-QIUQINGSHENG"   #Keysqiu应改为你自己的名字
git config --global user.email "2586597832@qq.com"   #2586597832@qq.com应改为你自己的邮箱

输入以上指令后，会在​C:\Users\Administrator​目录下生成​ .gitconfig​**配置文件（​此文件不能删除**​ ）
​
查看.gitconfig配置文件里的内容
​

1.3 生成ssh密钥

ssh-keygen -t rsa -C "2586597832@qq.com"    #2586597832@qq.com应改为你自己的邮箱

进入C:\Users\Administrator.ssh目录下，查看生成的SSH密钥（Linux在 /root/.ssh/ 里面，命令： cat /root/.ssh/id_rsa.pub​ ）

****然后拿公钥文件里面的内容去绑定就行了（**​注意是全部复制，gitee、github都是复制这个文件里面的内容**）
