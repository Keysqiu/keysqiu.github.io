2、Python中一个标准类的定义

==记住每一个方法都要带self，通过self才能访问类内的属性和方法，不加self，找的是类外的东西==

class Demo:
    def __init__(self):
        pass
    def api01(self):
        pass
    def api02(self):
        pass
# 以上代码定义了一个名为Demo的类。 
# - __init__(self)是类的构造函数，用于初始化对象的属性。在这个例子中，构造函数没有进行任何操作。
# - api01(self)是类的一个方法，它没有任何操作。
