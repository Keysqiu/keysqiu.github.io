ERROR Could not build wheels for XXX, which is required to install pyprojec

Created2025-11-30|Updated2026-08-23
|Post Views:

报错内容：

ERROR: Could not build wheels for XXX， which is required to install pyproject.toml-based projects

前提：看一下具体报错信息，是不是因为缺少另一个包导致这个包构建失败，如果是的话，先把另一个包装了，再装这个包

看完前提之后，还是没找到是因为缺少另一个包导致这个包构建失败的有效信息，那么可以先去CSDN搜**Pythonxxx（版本号）安装不上xxx（软件包名）**​ ******，**​有奇效(别问我怎么知道的)，因为有时候Python版本安装包时有对应的版本的，一般pip只会无脑下最新的，根本不管你适不适应！！！

！！！注意：这个是属于终极杀招，也就是你正常pip install安装一直报错（怎么都解决不了，呜呜呜┭┮﹏┭┮），才选择用这招！！！

解决办法（以pynacl包为例）：

① 在python 官网下载文件包，点击PyNaCl​下载
② 本地安装

其中E:\Download\PyNaCl-1.5.0-cp36-abi3-win_amd64.whl 为本地安装包的路径

pip install E:\Download\PyNaCl-1.5.0-cp36-abi3-win_amd64.whl

其他安装包类似的报错也可以用同样的方式解决
ERROR: Could not build wheels for XXX, which is required to install pyproject.toml-based projects

Python 官网上xxx安装包的地址为：

https://pypi.org/project/xxx/#modal-close #替换成需要的包名

如果实在装不上这个包，这时候就得考虑是不是python版本的问题了，因为有时候换一个python版本，包就猛猛安装好了，我真的艹了！！！
