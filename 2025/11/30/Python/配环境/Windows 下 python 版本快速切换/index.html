前言： 安装新版本Python

Python环境安装与配置[^1]python的安装可以看我之前的文章，本文主要是讲如何实现python 版本快速切换

1.查看当前python默认版本

使用命令，可以发现当前默认运行的Python版本

python -–version

例图如下：

2.修改环境变量

==在cmd下输入python打开的python程序的版本，取决于环境变量里哪个版本的python路径更靠前。==
如下图，可以看到本机添加了3.10版本和3.12版本的路径。如果希望默认使用python3.12，可以把3.12版本的路径上移到3.10路径前面即可（就这么简单，别怀疑！！！）。

[^1]: # Python环境安装与配置

# 二、开始安装

## **1.双击下载好的安装包，这里我以3.12为例**

![](/assets/Python%E7%8E%AF%E5%A2%83%E5%AE%89%E8%A3%85%E4%B8%8E%E9%85%8D%E7%BD%AE_image_1-20251130181901-nebrm1y.png)

## **2. 勾选**​******Add python.exe to PATH******​ **，然后再点击**​******Customize installation******​**进入到下一步**

![](/assets/Python%E7%8E%AF%E5%A2%83%E5%AE%89%E8%A3%85%E4%B8%8E%E9%85%8D%E7%BD%AE_image_2-20251130181901-2ibzmy2.png)

## **3.进入Optional Features后，不用操作，直接点击Next**

![](/assets/Python%E7%8E%AF%E5%A2%83%E5%AE%89%E8%A3%85%E4%B8%8E%E9%85%8D%E7%BD%AE_image_3-20251130181901-6jtb0of.png)

## **4.点击**​******Browse******​**进行自定义安装路径，也可以直接点击Install进行安装，点击install安装**

![](/assets/Python%E7%8E%AF%E5%A2%83%E5%AE%89%E8%A3%85%E4%B8%8E%E9%85%8D%E7%BD%AE_image_4-20251130181901-6651wpr.png)

## **5.点击Close ，安装完成**

![](/assets/Python%E7%8E%AF%E5%A2%83%E5%AE%89%E8%A3%85%E4%B8%8E%E9%85%8D%E7%BD%AE_image_5-20251130181901-ugzhb1b.png)
