这个博客怎么运作

博客里的文章都是我在 思源笔记 里的日常积累——写完笔记，自动同步、构建、发布到 GitHub Pages，写作即发布。

目前累计 200+ 篇，覆盖后端、前端、嵌入式、运维四大方向，右上角搜索框可以直接搜。

博客源码在 GitHub 上，你的 Star 是我更新的动力。搭博客遇到问题可以去技术支持提 Issue。
